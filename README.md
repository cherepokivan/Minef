# Minef — NeoForge 1.21.1

Серверный мод: создаёт **виртуального игрока** прямо внутри сервера и управляется командами.
Нужен, чтобы держать постоянного «игрока» для мостов вроде *Simple Voice Chat Discord Bridge*
(`/dvc start`, `/dvc group ...` выполняются от имени бота).

Ставится **только на сервер**, клиентам ничего устанавливать не нужно.

## Чем отличается от плагина для Paper

В плагине бот был сетевым клиентом (MCProtocolLib, подключение к самому себе) и мог зависать
на этапе configuration. Здесь бот — **фейк-игрок без сетевого подключения** (подход Carpet):
нет рукопожатий, вайтлиста, авторизации, Code of Conduct и т.п. Бот сразу полноценно «онлайн»
и стоит в режиме наблюдателя.

## Команды (нужен уровень прав 2 / оператор, работают и из консоли)

| Команда | Что делает |
|---|---|
| `/minef start` | запустить виртуального игрока |
| `/minef stop` | отключить |
| `/minef status` | онлайн ли бот |
| `/minef say <текст>` | без `/` — сообщение в общий чат от бота; с `/` — команда от имени бота |

Ответы бота (например, ссылка/канал от `/dvc start`) пересылаются тому, кто дал команду, в течение 30 секунд.

Пример:
```
/minef start
/minef say /dvc group create discord-bridge "" normal true
/minef say /dvc start
```
(Порядок аргументов `group create`: `<имя> [пароль] [тип] [persistent true/false]`.)

## Конфиг `config/minef-common.toml`

- `botName` — ник бота (по умолчанию `VoiceBridgeBot`)
- `autoStart` — запускать бота при старте сервера
- `startupDelaySeconds` — задержка автозапуска
- `commandPermissionLevel` — уровень прав бота для `/minef say /...` (по умолчанию 2)
- `startupCommands` — команды, которые бот выполнит сам после запуска, например:
  `["dvc group create discord-bridge \"\" normal true", "dvc start"]`

С `autoStart = true` и `startupCommands` мост поднимается сам после каждого рестарта сервера.

## Сборка

Нужна только JDK 21.

- **GitHub Actions:** залейте проект в репозиторий → вкладка *Actions* → *Build Minef* → *Run workflow* →
  готовый jar в *Artifacts*.
- **Локально:** `./gradlew build` → `build/libs/minef-1.0.0.jar`.

Положите jar в папку `mods` сервера NeoForge 1.21.1.

## Совместимость с другими модами (важно)

NeoForge перед каждой отправкой кастомного пакета проверяет, что у клиента есть нужный канал, и бросает
исключение, если его нет. Моды вроде **Sable** шлют свои пакеты при входе игрока без такой проверки.
Для фейк-игрока это роняло вход (`An unexpected error occurred trying to execute that command`).
Начиная с **1.0.1** у бота «есть все каналы» — пакеты модов просто уходят в никуда.

Также в 1.0.1:
- ошибка запуска больше не оставляет «полуживого» бота: он убирается, а в чат/консоль выводится причина
  (полный стектрейс — в `logs/latest.log`);
- обработчики событий мода обёрнуты в защиту — ошибка в моде не может уронить сервер
  (раньше исключение в автозапуске могло вызвать бесконечные перезапуски).

Если `/minef start` всё равно пишет ошибку — пришлите стектрейс из `latest.log` (строки с `[Minef]` и `Caused by`).

## Важные оговорки

- Код написан по исходникам Carpet (для 1.21) и API NeoForge, но **не компилировался и не запускался**
  в моей среде — при первой сборке возможны мелкие правки.
- Бот — спектатор, но всё же «игрок»: учитывается в онлайне и в списке игроков.
- Если у `voicechat-discord` для NeoForge другие требования к игроку (права и т.п.), поднимите
  `commandPermissionLevel`.
